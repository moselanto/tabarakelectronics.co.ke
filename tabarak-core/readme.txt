Companion plugin for the Tabarak Electronics theme. Adds business information,
product brands, SEO structured data and trust components.

== Description ==
This plugin provides the update-safe functionality layer for the Tabarak
Electronics theme: a Brands taxonomy for products, Organization / ElectronicsStore
structured data, a business information settings screen, and a [tabarak_trust_badges]
shortcode. Version 1.1.0 adds a Setup Wizard that installs required plugins and creates your store pages with ready-made content.

== Installation ==
1. Upload the plugin ZIP via Plugins > Add New > Upload.
2. Activate.
3. Go to the Tabarak menu to set your business details.
